# ADR-0011: 採用後のADRで変えてよいのは「状態」の行だけにする

- 状態: 採用
- 日付: 2026-11-12
- 関連: [ADR-0001](0001-record-decisions.md) の決定1を明確にする

## 状況

ADR-0001 は「採用後のADRは書き換えず、変更するときは新しいADRで置き換える」と定めている。一方、規約(conventions.md)は「旧ADRの状態を置き換え済みにする」として、状態の更新を認めていた。上位(ADR)と下位(規約)で、何を変えてよいかが食い違っていた。

この曖昧さのため、PR #2 で ADR-0005 と ADR-0007 の本文に「更新」の注記を追加し、レビューで規則違反と指摘された。

## 決定

- 採用後のADRで変えてよいのは、先頭の「状態」の行だけとする。
- 状態の行には、そのADRを置き換えた、または一部を変更したADRへのリンクを書く。
  - 例: `状態: 置き換え済み([ADR-0012](...))`、`状態: 採用(テスト環境は [ADR-0010](...) で変更)`
- 本文(状況・決定・理由・影響)は、誤字の修正を含めて変えない。
- 採用前(PRがマージされる前)のADRは、自由に直してよい。

ADR-0005 と ADR-0007 の本文への注記は取り除き、状態の行へ移した。

## 理由

- 読み手がADRを開いたとき、それがまだ有効か、どこで変わったかを最初の行で知る必要がある。リンクがなければ、後のADRをすべて読まないと分からない。
- 本文を変えないことで、「その時点で何を知っていて、なぜそう決めたか」が残る。これがADRを残す目的である(ADR-0001)。
- ADR-0001 を直接書き換えるとその規則自体に反するため、この明確化も新しいADRで行った(規約の「上位が誤りなら上位を明示的に変える」の手順どおり)。
