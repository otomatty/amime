# ADR-0035: 表示名とアイコンを本人が決め、カーソルと `[名前.icon]` に出す

- 状態: 採用(Cloudflare 上での動作は未確認。手元の Workers ランタイムで確認した)
- 日付: 2026-11-14
- 関連: [ADR-0032](0032-login-and-sessions.md)(利用者)、[ADR-0023](0023-presence.md)(他の人のカーソル)、[ADR-0012](0012-inline-notation.md)(`[名前.icon]` の記法)、[ADR-0034](0034-invites-and-members.md)(メンバー)

## 状況

ログインした人には、提供元から受け取った名前と画像が入っている(ADR-0032)。他の人のカーソルは、色だけで見分けていた(ADR-0023)。`[名前.icon]` は、名前の入った印を出すだけだった。US-11(表示名とアイコンを設定でき、`[名前.icon]` で自分のアイコンを本文に置ける)と、US-04(他の人のカーソルに、名前が見える)を満たす。

## 決定

### プロフィール

- 本人が、表示名とアイコンを変えられる(`PATCH /api/me`、画面は `/settings`)。送った項目だけを変える。
- 表示名は、1文字から50文字まで(絵文字も1文字と数える)。前後の空白は取り除く。改行など(制御文字、行の区切り U+2028、段落の区切り U+2029)は受け付けない。ログインの提供元から受け取った名前に含まれていたら、空白に置き換える。
- `[` や `]` を含む表示名は、`[表示名.icon]` と書けない。名前としては使えるので、禁じない。プロフィールの画面で、本文にアイコンを置けないことを伝える。
- アイコンは、画像の **https のURL** で指定する。空にすると、アイコンなし。画像をアップロードする仕組み(P5)ができるまでは、ほかの場所にある画像を指す。
- `[名前.icon]` が、その名前のページの画像を指すときは、本文の画像と同じく、http のURLも表示する(https に限るのは、本人が指定するアイコンだけ)。
- 最初の値は、最初にログインしたときに、提供元から受け取ったもの。そのあとのログインでは、上書きしない(ADR-0032)。

### `[名前.icon]`

- 画像は、プロジェクトごとに引く(`GET /api/projects/:project/icons/:name`)。プロジェクトを読める人なら、だれでも引ける。
  1. その名前の**ページ**に画像があれば、その画像(一覧のカードに出す、最初の画像)。
  2. なければ、その表示名の**メンバー**のアイコン。
  3. どちらもなければ、これまでどおり、名前の入った印を出す。
- 名前は、ページの名前と同じ決まりで照らし合わせる(大文字と小文字、空白かアンダースコアかを区別しない)。
- サーバーは、画像のURLを返すだけで、画像へ転送しない(このサイトのURLを、ほかのサイトへの入口にしない)。
- 画面は、同じ名前を、ページを開いているあいだ、1回だけ引く。画像を読み込めなければ、名前の文字に戻す。
- 画像を読み込むときに、いまのページのURLを、画像の置き場所に伝えない(`referrerpolicy="no-referrer"`)。

### カーソルの名前

- メンバーのカーソルには、その人の表示名を添えて配る。名前は、Worker が、ログインの状態から決めて、接続に付ける(画面が送ってきた名前は、使わない)。
- 画面は、カーソルの上に、名前の札を出す。色分けは、そのまま残す。
- 読むだけの人(メンバーでない人)のカーソルは、配らない(ADR-0033)。

## 理由(ユーザーストーリーから)

- **US-11**: 表示名とアイコンを設定でき、`[名前.icon]` で自分のアイコンを本文に置ける。
- **US-04**: 同じページにいる人が、だれなのかが分かる。色だけでは、だれのカーソルかが分からない。

## 検討した他の案

- **`[名前.icon]` を、メンバーのアイコンだけにする**: 人でないもの(プロジェクトの印、状態を表す印)のアイコンを作れない。ページの画像を先に引けば、ページを書くだけで、好きなアイコンを作れる。
- **アイコンのURLを、ページの読み込みと一緒に返す**: ページにどのアイコンがあるかを、サーバーが本文から調べることになる。書いた直後のアイコンには、間に合わない。
- **サーバーが、画像へ転送する(302)**: `<img>` にそのまま書ける。ただし、このサイトのURLから、メンバーが決めた好きなURLへ飛ばせるようになる。
- **提供元の名前と画像を、ログインのたびに取り込む**: 本人が変えたものを、上書きしてしまう。

## わかっている制約

- 表示名を変えても、つないだままの接続のカーソルには、前の名前が出る(つなぎ直すと、新しい名前になる)。
- アイコンの画像は、ほかの場所に置いたもの。見た人のブラウザは、その置き場所に、画像を取りに行く(置き場所には、見た人のIPアドレスが分かる)。本文の画像(`[画像のURL]`)と同じ。
- 同じ表示名のメンバーが2人いると、`[名前.icon]` は、先に参加した人のアイコンになる。
- メンバーのアイコンは、公開のプロジェクトでは、メンバーでない人も、表示名を指定して引ける。
- プロフィールの画面から、参加しているプロジェクトの一覧や、退会は、まだできない。
