# ADR-0012: 行内記法の解析結果の形と、表示の切り替え

- 状態: 採用(コードブロックとテーブルは [ADR-0013](0013-block-notation.md) で追加)
- 日付: 2026-11-12
- 関連: [ADR-0005](0005-editor-architecture.md)、[ADR-0010](0010-editor-input.md)

## 状況

US-02 は「括弧で囲む程度の軽い記法で書ける」ことと、「カーソルのある行だけ記法がそのまま見え、他の行は装飾された表示になる」ことを求めている。

エディタは1文字ごとの要素に生のテキストでの位置を持たせ、押された要素からカーソル位置を求めている(ADR-0010)。記法を隠して表示する行でも、この仕組みを保つ必要がある。

## 決定

### 解析結果の形

- 解析は `packages/parser` の `parseLine` が行ごとに行う。純粋関数で、どんな文字列でも例外を出さない。
- すべてのノードが、行の生のテキストの中で占める範囲(`start`〜`end`)を持つ。
- 記号と中身に分かれるノードは、中身の範囲 `content` を持つ。`start`〜`content.start` と `content.end`〜`end` が記法の記号にあたる。
- ノードの列は、インデントより後ろを隙間も重なりもなく覆う。入れ子の子は、親の `content` を同じように覆う。この性質はプロパティテストで保証する。
- 入れ子を解釈する深さは8段までとし、それより深い部分はただの文字列にする。

### 表示

- **編集中の行**(編集欄にフォーカスがあるときの、カーソルのある行)は、記号も含めて生のテキストをそのまま見せる。記号は薄い色にし、太字などの見た目は保つ。リンクや画像は実体にしない。
- **それ以外の行**は記号を描画せず、リンク・装飾・画像として見せる。見えている文字は、生のテキストでの位置をそのまま持つ。
- 編集欄からフォーカスが外れたら、すべての行を装飾して見せる。
- 1行目はタイトルとして大きく表示し、記法を解釈しない。
- 装飾して表示している行のリンクを押したら、カーソルは動かさず、リンク先へ移動する。
- 文字は、記法の範囲ごとに1文字ずつの要素に分ける。「]」の直後に結合文字が続くような場合でも、記号だけを隠して文字は表示できる。
- 行の最後の文字より右を押したら行末に、最初の文字より左を押したら行頭にカーソルを置く。見えている文字の端にすると、隠れた「]」の内側に入力されてしまうためである。
- 編集欄(textarea)は行より前に置く。Tab の順序が「編集欄 → 本文中のリンク」になる。

### リンク先

- ページへのリンクは、いまのページからの相対パス(`./タイトル`)にする。空白はアンダースコアにする。
- 外部リンクは別のタブで開き、`rel="noopener noreferrer"` を付ける。
- ページを表示する経路(ルーティング)は P2・P3 で作る。それまでは、リンクを押しても同じサンプル画面が開く。

## 根拠にした公開ヘルプ

- [ブラケティング](https://scrapbox.io/help-jp/ブラケティング): ページリンク、アイコン、画像
- [文字装飾記法](https://scrapbox.io/help-jp/文字装飾記法): 太字・斜体・打ち消し、記号の組み合わせ、使える記号の一覧
- 利用者向けの初期ページ「Cosenseの使い方」: ハッシュタグ、インデント

## 公開ヘルプで確認できず、こちらで決めた挙動

実際の挙動と違うことが分かったら、テストを直して合わせる。

| 項目                           | 決めた挙動                                                                                                                                                                                      |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 文中の `#`                     | 直前が空白か行頭のときだけタグにする(「C#」を巻き込まないため)                                                                                                                                  |
| `[ a ]` のような前後の空白     | リンク先のタイトルからは取り除く                                                                                                                                                                |
| `[画像URL 表示文字]`           | 画像ではなく、画像へのリンクにする                                                                                                                                                              |
| 括弧の入れ子 `[a [b] c]`       | 外側はリンクにせず、内側だけをリンクにする                                                                                                                                                      |
| バッククォートと括弧の優先順位 | バッククォートの対を最優先にする。行の左から順に対にし、中の括弧は記法として数えない。``[* a`]`b]`` は装飾の中にコード `]` がある形になり、``[* a`b] c` `` は装飾にならず `b] c` がコードになる |
| タグと本文中のURLの終わり      | 空白・括弧・バッククォートの手前まで                                                                                                                                                            |
| タイトル行                     | 記法を解釈しない                                                                                                                                                                                |
| 下線 `[_ 文字]`                | 下線として表示する                                                                                                                                                                              |

## 安全性

- リンク先を作るときは、対になっていないサロゲート(壊れた文字)を置換文字に置き換えてからエンコードする。そのままでは `encodeURIComponent` が例外を出し、描画が止まるためである。
- 外部リンクと画像のURLは、`http://` か `https://` で始まるものだけを認める。`javascript:` などは、ただのページタイトルとして扱われる。この性質もプロパティテストで保証する。
- 画像は、書かれたURLからそのまま読み込む。読み手のIPアドレスが画像の置き場所に伝わる(本家と同じ)。見ているページのURLは伝えない(`referrerpolicy="no-referrer"`)。画像を自前で保存する P5 で、外部画像の扱いをあらためて決める。

## 理由

- ノードが位置を持つので、記号を隠す行でも、見えている文字に生のテキストでの位置をそのまま付けられる。クリック位置からカーソル位置を求める仕組み(ADR-0010)を、表示の切り替えに関係なく使える。
- 編集中の行と他の行を同じ解析結果から描画するので、「見えている装飾」と「書いてある記法」が食い違わない。
- 行ごとに独立した解析なので、変更のあった行だけ解析と描画をやり直せばよい。

## まだ扱っていないもの

- 複数行にまたがる記法(コードブロック、テーブル)。前の行の状態が必要になるため、行ごとの解析の外側に、ページ全体を見る処理を足す。
- リンク先のページが存在するかどうかによる表示の違い(P3)。
- 数式の組版、アイコンの画像表示(P4)、動画や地図の埋め込み、Gyazo など拡張子のない画像URL。
- `[[画像URL]]` や `[[名前.icon]]` を大きく表示する挙動。
- 文字装飾の独自の記号(`!` や `#` など)の見た目。記号は `data-deco` 属性に出力してあり、UserCSS(P6)で使えるようにする。
