# ADR-0028: ページの名前を変えたら、そのページへのリンクを書き換える

- 状態: 採用(Cloudflare 上での動作は未確認。手元の Workers ランタイムで確認した)
- 日付: 2026-11-13
- 関連: [ADR-0024](0024-page-identity-and-project-index.md)(名前の変更)、[ADR-0025](0025-page-index-and-list.md)(台帳のリンク先の表)、[ADR-0027](0027-related-pages-and-missing-links.md)、[ADR-0016](0016-changes-and-line-ids.md)

## 状況

ページの名前は、1行目を書き換えると変わる(ADR-0024)。リンクは名前で書くので、名前を変えると、他のページにあるそのページへのリンクが、まだないページへのリンクになっていた(US-08)。

## 決定

### 書き換えの流れ

1. 台帳(`ProjectDO`)は、保存されているページの名前が変わったとき、そのページへリンクしているページ(台帳のリンク先の表から分かる)ごとに、**書き換えの予定**を1つ台帳に入れる。名前の変更と同じトランザクションで入れる。
2. 台帳は、アラームで、予定を古い順に20件ずつ行う。ページごとに `PageDO` の `rewriteLinks(前の名前, 新しい名前)` を呼ぶ。残りがあれば、続けて行う。
3. `PageDO` は、本文の中の、前の名前へのリンクを書き換える。書き換えは、**ふつうのコミットと同じ**に扱う(バージョンを進め、開いている端末に配信し、台帳への反映を予約する)。開いている画面のリンクは、その場で書き換わる。
4. 台帳は、書き換えが済んだら、リンク先の表も、書き換えた結果に合わせて直し(新しい名前へのリンクを足し、前の名前へのリンクが残っていなければ消す)、予定を消す。

名前を変える操作そのもの(1行目の書き換えと、その反映)は、書き換えを待たない。

### 何を書き換えるか

- `[前の名前]` を `[新しい名前]` に、`#前の名前` を `#新しい名前`(空白はアンダースコア)にする。名前は、正規化して照らし合わせる。
- 1行目(タイトル)と、コードの中は書き換えない。他のプロジェクトへのリンク、アイコン(`[名前.icon]`)、表示文字つきの外部リンクは書き換えない。
- 新しい名前を `[名前]` と書いても、そのページへのリンクとして読めないとき(括弧を含む、URL、装飾の記法になる、など)は、そのリンクを書き換えない。タグは、タグとして書けなければ `[名前]` にする。
- 書き換えると1行の長さの上限(ADR-0016)を超える行は、書き換えない。
- 書き換えた行を読み直して、リンクの読まれ方が変わってしまうとき(名前の中のバッククォートが、他の記号と組になってコードになる、など)は、その行を書き換えない。
- 書き換えは、記法の解析(`@amime/parser`)の `renameLinks` が行う。

### 書き換えないとき

- 大文字小文字と、空白かアンダースコアかの違いだけの変更(同じ名前として読める)。
- 名前を変えられなかったとき(同じ名前のページがある、1行目が空、など。ADR-0024)。
- 開いただけで保存していなかったページに、別の名前を付けたとき(前の名前のページは、なかった)。

### リンクを書いたページの反映が、名前の変更より遅れたとき

リンクは、書いてから約2秒後に台帳に載る(ADR-0025)。そのあいだにリンク先の名前が変わると、そのリンクは、上の 1 の予定に入らない。

- 台帳は、名前の変更(前の名前と、新しい名前)を**1時間**覚えておく。
- そのあいだに台帳に新しく載ったリンクが、前の名前へのリンクなら、書き換えの予定に入れる。
- 前の名前で、新しいページができていたら、書き換えない(そのページへのリンクとして読む)。
- すでに台帳が知っているリンク(書けない名前に変わったので、前の名前のまま残したもの)は、予定に入れ直さない。

### 続けて名前を変えたとき

- 書き換える前に、もう1度名前が変わったら、まだ済んでいない予定の行き先を、新しい名前に付け替える。
- 書き換えたあとに名前が変わったら、台帳のリンク先の表(4 で新しくしてある)から、そのページを見つける。
- 書き換えているあいだに名前が変わったら、書き換えた先の名前から、いまの名前へ、続けて書き換える。

### 失敗したとき

- 書き換えに失敗したページは、30秒後にやり直す。5回失敗したら、あきらめる(リンクは、前の名前を指したまま残る)。他のページの書き換えは止めない。
- `rewriteLinks` は、何度呼んでも結果が同じになる(書き換えるリンクが残っていなければ、何もしない)。応答が届かずにやり直しても、二重には書き換わらない。
- ページを削除したら、そのページの書き換えの予定も消す。

## 理由(ユーザーストーリーから)

- **US-08**「タイトルを変えると、他のページにあるそのページへのリンクも新しいタイトルに書き換わる」「大文字小文字と、空白かアンダースコアかの違いだけなら、同じページとして扱われる」に対応する。
- **US-01**(考えを止めずに書ける): 名前を変えた人を、リンクしているページの数だけ待たせない。書き換えは、台帳のアラームで、少しずつ行う。
- **US-04 / US-05**: 書き換えをふつうのコミットとして配信するので、そのページを編集中の人の入力は、同じ行でも失われない(行の中の統合。ADR-0022)。

## 検討した他の案

| 案                                                              | 採用しなかった理由                                                                                                     |
| --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 本文は書き換えず、前の名前から新しい名前への転送を、台帳に持つ  | 本文に古い名前が残る。前の名前で新しいページを作れなくなるか、転送とぶつかる。エクスポートしたときにも、リンクが切れる |
| リンクを、名前ではなくページのIDで本文に書く                    | 記法が変わる。まだないページへのリンクを書けない。本文をそのまま読めなくなる                                           |
| 名前を変えた反映(`index`)の中で、すべてのページを書き換える     | リンクしているページが多いと、1度の呼び出しでできる通信の数を超える。途中で失敗すると、やり直せない                    |
| 名前を変えた人の画面が、リンクしているページを1つずつ書き換える | 画面を閉じると、途中で止まる。画面を通らない変更(他の端末、復元)では、書き換わらない                                   |
| 書き換えたページの反映を待って、台帳のリンク先の表を新しくする  | 反映を待つあいだ(約2秒)にもう1度名前を変えると、そのページを見つけられず、リンクが前の名前のまま残る                   |
| Cloudflare Queues で、ページごとの書き換えを配る                | 費用と設定が増える。台帳の表とアラームで、順序とやり直しを足りるだけ扱える                                             |

## わかっている制約

- 書き換えは、名前の変更が台帳に反映されてから(書き換えが落ち着いて約2秒後)始まり、リンクしているページが多いほど、終わるまでに時間がかかる。そのあいだ、まだ書き換わっていないリンクは、まだないページへのリンクになる。
- 名前を少しずつ打ち直すと、途中の名前でも書き換えが走ることがある(打つ手が約2秒止まるたびに、名前が変わる)。リンクしているページには、そのぶんのコミットが増える。
- 名前を変えた直後に、前の名前で新しいページを作ると、まだ済んでいない書き換えは、そのまま行われる(新しいページではなく、名前を変えたページを指すようになる)。
- 名前を変えてから1時間のあいだに、前の名前へのリンクを新しく書くと、新しい名前に書き換わる(前の名前のページを、これから作るつもりで書いたリンクでも)。1時間を過ぎてから書いたリンクは、まだないページへのリンクとして残る。
- 台帳のリンク先の表に載っていないリンク(1ページに1,000件を超えた分。ADR-0025)は、書き換わらない。
- 5回失敗してあきらめた書き換えは、記録に残らない。リンクは、前の名前を指したまま残る。
- 通信が切れている端末が、書き換えの前の行を編集していたら、つながったときに、行の中の統合(ADR-0022)で両方を残す。同じリンクの中を書き換えていたときは、どちらの文字も残り、リンクの名前が崩れることがある。
- アイコン(`[名前.icon]`)は書き換えない。アイコンを台帳のリンク先に含めるかどうかは、アイコンを扱うとき(P4)に決める。
