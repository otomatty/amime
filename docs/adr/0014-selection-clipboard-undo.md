# ADR-0014: 範囲選択・クリップボード・取り消しの扱い

- 状態: 採用(取り消しの方式は、P2で同期を入れるときに置き換える)
- 日付: 2026-11-12
- 関連: [ADR-0005](0005-editor-architecture.md)、[ADR-0010](0010-editor-input.md)

## 状況

エディタは表示もカーソルも自前で描画している(ADR-0010)。そのため、範囲選択、コピー・切り取り、取り消し・やり直しは、ブラウザの機能に任せられず、自前で持つ必要がある。

## 決定

### 範囲選択

- エディタの状態に、選択の始点(`anchor`)を持たせる。選択範囲は `anchor` とカーソルのあいだ。始点がないか、カーソルと同じ位置なら、選択していない状態とする。
- 文書を変えない操作(カーソル移動)が返す状態には始点を含めない。移動すれば自然に選択が解ける。Shift+矢印やドラッグは、始点を保ったままカーソルだけを動かす。
- 選択したまま文字を入れると、選択した範囲と置き換わる。Backspace と Delete は、選択した範囲だけを消す。
- 選択したまま日本語入力を始めても、変換中は文書を変えない。確定したときに、選択した範囲との置き換えを1回の編集として行う。変換を取り消せば何も変わらず、確定後の取り消しも1回で選択した状態まで戻る。
- Tab と Shift+Tab は、選択にかかるすべての行のインデントを変える。選択が行頭で終わっているとき、その行は対象にしない。テーブルの行でも、選択しているあいだは Tab をインデントにする(選択した文字をタブ文字で置き換えない)。
- 選択とカーソルは、編集欄にフォーカスがあるときだけ表示する。
- ドラッグ中は、マウスの動きをウィンドウ全体で監視する。編集欄の外へ出ても選択を続けられる。
- 行のない場所(テーブルの右の余白、編集欄の外)では、押した高さに最も近い行で位置を決める。すべての行より上なら文書の先頭、下なら文書の末尾とする。

### コピーと切り取り

- コピーされるのは、選択した範囲の生のテキスト。記法やインデントは書いてあるとおりに含め、行は改行でつなぐ。
- `copy` / `cut` イベントで、クリップボードに入れる内容を自分で指定する。
- コピー・切り取りのキーが押された時点で、選択した文字列を textarea に入れて選択しておく。何も選択されていない textarea では、ブラウザによっては `copy` / `cut` のイベントが届かないためである。イベントの処理が済んだら textarea を空に戻す。
- 貼り付けは、これまでどおり textarea への入力として受け取る。

### 取り消しとやり直し

- 文書の状態(行の配列、カーソル、選択)をそのまま履歴に積む。取り消すと、編集の前の状態にカーソルや選択ごと戻る。
- カーソルの移動や選択のように文書を変えない操作は、履歴に積まない。
- 続けて打った文字、続けて押した Backspace、続けて押した Delete は、それぞれ1回の取り消しにまとめる。種類が変わるか、1秒より長く間が空くか、あいだにカーソルを動かしたら、別の単位にする。改行と、改行を含む貼り付けは、必ず単独の単位にする。
- 覚えておく取り消しの単位は500まで。

### キー

- Mac では Command キー、それ以外では Ctrl キーとの組み合わせを使う: すべて選択(A)、取り消し(Z)、やり直し(Shift+Z。Mac 以外では Y も)。
- コピー・切り取り・貼り付けのキーは、エディタでは扱わずブラウザに任せる(イベントとして受け取る)。
- ショートカットの英字は、キーの文字が英字ならその文字で、英字にならない配列(キリル文字など)ではキーの位置で判定する。

## 理由(ユーザーストーリーから)

- **US-01 / US-03**: 書いたあとで構造を組み替えるには、範囲を選んで動かす・消す・インデントする操作が要る。
- **US-05(書いたものを失わない)**: 誤って消したものを取り消しで戻せることは、保存と同じくらい安心に効く。
- 選択を「始点を持つかどうか」だけで表すと、既存の操作のほとんどを変えずに済む。カーソルを動かす操作は始点を返さないので、選択の解除を個別に書く必要がない。

## P2で置き換えること

いまの取り消しは、文書全体の状態を巻き戻す方式である。共同編集(US-04)では、この方式は使えない。自分が取り消したときに、そのあいだに他の人が書いた内容まで消してしまうためである。

P2では、取り消しを「自分が行った変更を打ち消す変更を作って送る」方式に置き換える。行IDによる変更の表現(ADR-0006)があれば、自分の変更だけを選んで打ち消せる。履歴を扱う関数(`applyEdit`、`undo`、`redo`)の呼び出し方は変えず、中の持ち方を変える。

## まだ扱っていないもの

- ダブルクリックでの単語の選択、トリプルクリックでの行の選択。
- 選択した範囲に対するポップアップメニュー(P6)。
- タッチ操作での選択(P6)。
- 上下の矢印キーでの移動を、見た目の横位置に合わせること。
- 行を子の行ごと上下に動かす操作(US-03)。
- Mac の Control キーとの組み合わせ(行頭・行末への移動など)。
- 選択の読み上げ([#3](https://github.com/otomatty/amime/issues/3))。
