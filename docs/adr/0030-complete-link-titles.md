# ADR-0030: リンクを書いている途中に、ページの名前を補完する

- 状態: 採用(Cloudflare 上での動作は未確認。手元の Workers ランタイムで確認した)
- 日付: 2026-11-13
- 関連: [ADR-0029](0029-search-pages-by-title.md)(名前の合わせ方と、探すAPIを使う)、[ADR-0010](0010-editor-input.md)

## 状況

リンクは、ページの名前を正しく書かないと、つながらない。名前をうろ覚えのまま書くと、まだないページへのリンクが増える(US-07)。

## 決定

### いつ候補を出すか

- カーソルが、**書いている途中のリンク**の中にあるとき、入力した名前の一部で候補を探して出す。
  - `[名前`: 開いた括弧からカーソルまで。閉じる括弧がもうあってもよい。
  - `#名前`: `#` からカーソルまで。
- 次のときは、出さない。
  - 名前をまだ1文字も書いていない(`[` や `#` を打っただけ)。
  - 他の記法として読める(`[* 太字`、`[$ 数式`、`[https://…`、`[/プロジェクト/…`、`[[強調`)。
  - 1行目(タイトル)、コードブロックの中、`` ` `` で囲んだコードの中、コマンドやヘルプの行(`$ …`、`% …`、`? …`。リンクにならない)。
  - 日本語入力の変換中、範囲を選択しているあいだ、編集欄にフォーカスがないあいだ。
- テーブルの行では、カーソルのあるセルの中だけを、リンクとして読む(記法は、セルをまたがない)。補完しても、他のセルは変えない。
- 候補は、名前で探すAPI(ADR-0029)で探す。入力が止まってから 0.1 秒後に探す。合う名前がなければ、何も出さない。
- `[名前]` と書いても、そのページへのリンクにならない名前(括弧を含む、URLやアイコンとして読まれる、など)は、候補に出さない。書いたものを記法として読み直して、確かめる(リンクの書き換えと同じ。ADR-0028)。
- 候補は、カーソルのすぐ下に出す。

### 選び方

- 候補は、**最初はどれも選んでいない**。上下の矢印キーで選び、Enter で補完する。候補を押しても補完する。選んだ候補は、一覧の見えるところに入るようにスクロールする。
- 候補を選んでいないときの Enter は、改行する。候補が出ていても、書く手を止めない。
- Esc で、候補を閉じる。同じリンクを書いているあいだは、もう出さない。そのリンクから離れたら(消した、別のリンクへ移った)、閉じたことを忘れる。この Esc は、編集欄から抜ける準備(Esc のあとの Tab)にはしない。
- 候補が出ているあいだも、上下の矢印キー・Enter・Esc のほかのキーは、いつもどおりに働く(Tab は字下げ)。

### 補完のしかた

- 括弧のリンクは、括弧の中を名前に置き換え、閉じる括弧がなければ足す。カーソルは、閉じる括弧の後ろに置く。
- タグは、タグのまま補完する(名前の空白は、アンダースコアにする)。タグとして書けない名前は、`[名前]` にする。
- 補完は、1回の取り消しで元に戻る。
- どこがリンクの途中か(`linkQueryAt`)と、補完のしかた(`completeLink`)は、`@amime/editor-core` の純粋な関数にする。

## 理由(ユーザーストーリーから)

- **US-07**「リンクを書いている途中に、既存のページ名が候補として出る」に対応する。
- **US-01**(考えを止めずに書ける): 補完は、書くことの邪魔にならないことを優先する。候補を選ばなければ、Enter は改行のままにする。まだないページへのリンクを書くことも、ふつうの使い方である。

## 検討した他の案

| 案                                                       | 採用しなかった理由                                                                                           |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 最初の候補を選んだ状態にして、Enter で補完する           | リンクを書いている途中で改行しようとすると、意図しない名前が入る。新しい名前のリンクを書くたびに、Esc が要る |
| Tab で候補を選ぶ・補完する                               | Tab は字下げに使っている(ADR-0010)。候補が出ているかどうかで Tab の意味が変わると、字下げの手が狂う          |
| `[` を打った時点で、最近のページを候補に出す             | 装飾(`[* 太字]`)など、リンクでない括弧を書くたびに候補が出る                                                 |
| すべてのページの名前を画面に読み込み、画面の中で絞り込む | ADR-0029 と同じ理由(ページが増えると、読み込む量が増える)                                                    |
| 候補を、編集欄の外(ページの下など)の決まった場所に出す   | 視線がカーソルから離れる                                                                                     |

## わかっている制約

- 候補に出るのは、台帳に反映されたページである(ADR-0029)。作ったばかりのページは、すぐには出ない。
- 入力のたびに(0.1 秒の間をおいて)、名前を探す問い合わせを行う。通信が切れているあいだは、候補が出ない。
- スマートフォンなど、矢印キーのない端末では、候補を押して選ぶ。
- 候補が、画面の下端からはみ出すことがある(カーソルの上には出さない)。
- 試し書きのページ(保存されない)では、補完しない。
