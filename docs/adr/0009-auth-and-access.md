# ADR-0009: 認証は Google ログイン、参加は招待制にする

- 状態: 採用(セッションの持ち方は [ADR-0032](0032-login-and-sessions.md) で変更)
- 日付: 2026-11-11

## 状況

依頼者への確認(2026-11-11)で、利用形態は「招待制のチーム」、ログイン方式は「Google ログイン」と決まった。

## 決定

- ログインは Google の OAuth 2.0 / OpenID Connect で行う。認証は差し替えられる層として実装し、他の方式を後から追加できるようにする。
- ユーザーは複数のプロジェクトに所属できる。プロジェクトへの参加は招待リンクで行う。
- プロジェクトは公開(誰でも閲覧可、編集はメンバーのみ)と非公開(メンバーのみ)を選べる。
- 新しいプロジェクトを作れるユーザーを制限する設定を持つ(自由登録の公開サービスにはしない)。
- セッションは、署名付きの HttpOnly Cookie で保持する。
- ユーザー・プロジェクト・所属は D1 に保存する。

## P4までの扱い

認証が入るまで、公開環境に書き込み可能なAPIを置かない。P0の時点でHTTPとして公開しているのは `/api/health` だけで、`PageDO` はテストからRPCで呼ぶ。P2で編集のAPIを追加する場合は、認証が入るまでデプロイ先を Cloudflare Access で保護するか、ローカルとプレビュー環境に限定する。

## 依頼者に用意してもらうもの(P4の開始時)

- Google Cloud の OAuth クライアント(クライアントIDとシークレット、リダイレクトURI)
- 本番のドメイン

## 理由(ユーザーストーリーから)

- **US-11 / US-12**: チームのメンバーが、新しいパスワードを作らずに参加できる。招待リンクを受け取り、Google でログインするだけで書き始められる。
- 招待制に絞ると、スパム対策や通報の仕組みを初期に作らずに済み、編集体験の実装に時間を使える。
