# ADR-0036: 画面の見た目は「静かな紙」にする

- 状態: 採用
- 日付: 2026-11-14
- 関連: [ADR-0002](0002-scope-and-non-goals.md)(本家の見た目を写さない)、[ADR-0025](0025-page-index-and-list.md)(ページの一覧)、[ADR-0029](0029-search-pages-by-title.md)(ページを探す欄)

## 状況

P4 までで、機能はそろってきた。見た目は、機能を足すたびに、その場で付けてきた。入力欄・ボタン・リンクは、ブラウザの素の見た目のまま。ヘッダーは、大きな題名とログインの状態で、上の場所を広く使う。ページでは、保存の状態と操作のボタンが、右上に文字で浮いている。狭い画面では、列の多い表が、画面の外にはみ出す。

依頼者に、方向の違う3つの案(A 静かな紙 / B 作業机 / C つながりの地図)を、ページの一覧とページの2画面で見せ、A が選ばれた。

## 決定

見た目の方針を「静かな紙」とする。紙の色の地に、1段組み。飾りを足さず、文字の大きさ・余白・線で、まとまりを見せる。

### 色と形

- 色、角の丸み、部品の高さ、幅は、`app.css` の変数から取る。部品ごとに、値をじかに書かない。
- 地は紙の色(`--color-bg`)、本文や設定を載せる「紙」は、少し明るい色(`--color-paper`)に、薄い線の枠。影は、重なって出るもの(候補の一覧)にだけ使う。
- 色は、リンクの青緑(`--color-link`)を1つだけ使う。主な操作のボタン、いま選んでいるもの、リンクが、この色。警告と、元に戻せない操作は、`--color-warning`。
- 補助の文字(`--color-muted`)は、紙の色の上で読み取れる濃さにする(コントラスト比 4.5 以上)。これまでの色(`#8a857a`)は足りなかったので、濃くした(`#6b665c`)。
- 文字は、これまでと同じ(`Hiragino Sans`、`Noto Sans JP`)。

### 部品

- ボタン・入力欄・選択欄は、同じ高さ(40px)、同じ角の丸み、同じ枠にする。本文のそばに置く控えめなボタン(ページの固定・削除)は、36px で、枠を出さない。
- **狭い画面(幅 640px まで)では、どちらも 44px にする**(指で押すため)。
- ボタンは、3種類。
  - 主な操作(`type="submit"` か、`primary`): その画面で、いちばんしてほしいこと(作る、保存する、参加する、招待リンクを作る)。1つの画面に、1つまで。
  - ふつうの操作: 枠だけ。
  - 元に戻せない操作(`danger`): 削除する、メンバーを外す、プロジェクトから抜ける。
- リンクは、下線なし(重ねたときに、下線)。文の中のリンクは、色だけに頼らず、下線も付ける。
- キーボードで選んだものには、同じ枠(リンクの色、2px)を出す。

### 配置

- ヘッダーは、細い1段。左に「Amime / プロジェクト」、右に、ページを探す欄と、ログインの状態。画面の端から端まで、下に線を引く。
- 中身は、幅を決めて、まんなかに置く。一覧は 1040px まで、紙(ページ、設定、プロフィール、招待)は 800px まで。
- ページでは、本文の上の1段に、左から、保存の状態、接続の状態、右に、ページの操作を並べる。
- カードは、収まる行数だけを出す(本文の冒頭を、ふつうは3行。「固定」の印があれば2行。画像があれば1行)。途中で切れた行を見せない。
- **狭い画面でも、画面の全体が、横にはみ出さない。** ヘッダーは、探す欄を下の段に回す。列の多い表は、表の枠の中で、横に動かす。

### 確かめ方

見た目そのものは、自動では確かめられない。崩れたときに気づけるように、次のことを E2E で確かめる(`e2e/tests/layout.spec.ts`)。

- スマートフォンの幅で、主な画面が、横にはみ出さない(長いコード、列の多い表、切れ目のない長い語のあるページを含む)。
- パソコンの幅で、ヘッダーが1段に収まる。
- ボタンと入力欄の高さ(パソコンで 36px 以上、スマートフォンの幅で 44px 以上)。
- ページで、保存の状態と操作が、同じ段に並ぶ。

## 検討した他の案

- **B 作業机**(左に、探す・作る・固定・最近の更新を常に置く。白と寒色のグレー。一覧は表): ページが増えたときの行き来は速い。狭い画面では、左の欄が上に回り、本文が下がる。左の欄の出し分けを作る必要がある。
- **C つながりの地図**(暗い地に、リンクだけを琥珀色で見せる。関連するページを、本文の横に常に出す): Amime らしさは、いちばん出る。好みが分かれ、明るい版も別に要る。一覧にリンク先を出すには、新しいデータが要る。
- **部品のライブラリやCSSの枠組みを入れる**: いまの画面の数なら、変数と、素の要素への決まりで足りる。入れると、見た目を決める場所が増える。

## わかっている制約

- スマートフォンで、**幅に合わせて並ぶ**ようにしただけ。指での編集(選択、日本語入力、行の移動)は、確かめていない(P6)。
- 暗い色の画面は、ない。
- 「メンバーと設定」への入口は、ページの一覧の右上に、文字のリンクのまま。
- 見た目は、Chromium でだけ確かめた。Safari / Firefox では、確かめていない。
