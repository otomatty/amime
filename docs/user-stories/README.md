# ユーザーストーリー

設計とテストの出発点です。各ストーリーの受け入れ基準が、テストとして実装されます。食い違いがあった場合は、ADR・テスト・コードよりこの文書を優先します([conventions.md](../conventions.md))。

登場人物

- **書き手**: ページを書くチームのメンバー
- **読み手**: ページを読み、たどる人(書き手を兼ねる)
- **管理者**: プロジェクトを作り、メンバーを招く人

フェーズ: P0 基盤 / P1 記法とエディタ / P2 保存と共同編集 / P3 リンク・検索・一覧 / P4 認証とプロジェクト / P5 画像とバックアップ / P6 拡張・履歴・PWA

---

## 書く

### US-01 思いついたらすぐ書ける(P1)

書き手として、保存や書式を意識せずに書き始めたい。考えを止めずに書き留めたいからだ。

- 行頭に空白(半角スペース・タブ・全角スペース)を入れると、その数だけ字下げされた箇条書きになる。
- インデントされた行で改行すると、次の行も同じ深さで始まる。
- 保存の操作がない。入力は自動で保存される。
- 1行目がページのタイトルになる。

### US-02 記法で表現できる(P1)

書き手として、括弧で囲む程度の軽い記法で、リンク・強調・コード・表・画像を書きたい。マウスを使わずに構造を作りたいからだ。

- `[ページ名]` はページへのリンク、`#タグ` も同じくリンクになる。
- `[* 文字]` などの装飾、`[URL 文字]` の外部リンク、画像や動画のURLの埋め込みが表示される。
- `code:ファイル名` に続く字下げされた行はコードブロック、`table:名前` に続く行は表になる。
- カーソルのある行だけ記法がそのまま見え、他の行は装飾された表示になる。

### US-03 かたまりごと動かせる(P1)

書き手として、箇条書きのかたまりを、子の行ごと字下げしたり上下に動かしたりしたい。書いたあとで構造を組み替えたいからだ。

- 行とその子孫の行を、まとめて字下げ・字上げできる。
- 行とその子孫の行を、まとめて上下に移動できる。
- 操作はキーボードだけで行える。

## 一緒に書く

### US-04 同じページを同時に編集できる(P2)

書き手として、他の人が書いている内容をその場で見ながら、同じページに書き込みたい。会議や議論をページ上で進めたいからだ。

- 他の人の変更が、再読み込みなしで反映される。
- 別々の行への同時編集は、どちらも失われない。
- 同じ行への同時編集も、どちらの入力も残る。
- 他の人のカーソル位置と名前が見える。
- 全員の画面が、最終的に同じ内容になる。

### US-05 書いたものを失わない(P2)

書き手として、通信が切れたりタブを閉じたりしても、書いた内容が残っていてほしい。安心して書き続けたいからだ。

- 通信が切れている間の入力は、復帰後に送信される。
- 未保存の変更があることが、画面で分かる。
- サーバーが受け付けた変更は、再起動後も残っている。

### US-06 いつ誰が書いたか分かる(P6)

読み手として、行ごとの新しさと書いた人、ページの過去の状態を知りたい。情報の鮮度を判断したいからだ。

- 行ごとに、最後に更新した人と時刻が分かる。
- 最近更新された行が、見た目で分かる。
- ページを過去の時点の状態で表示できる。

## つながる・見つける

### US-07 リンクで自然につながる(P3)

読み手として、いま見ているページに関係するページを、分類せずに見つけたい。フォルダを設計せずに知識を育てたいからだ。

- ページの下に、そのページへリンクしているページと、同じリンクを持つページ(2ホップ先)が並ぶ。
- まだ存在しないページへのリンクは、見た目で区別できる。開くとそのタイトルで新しいページを書き始められる。
- リンクを書いている途中に、既存のページ名が候補として出る。

### US-08 タイトルを変えてもリンクが切れない(P3)

書き手として、ページのタイトルを後から自由に変えたい。最初から良い名前を付けられるとは限らないからだ。

- タイトルを変えると、他のページにあるそのページへのリンクも新しいタイトルに書き換わる。
- 大文字小文字と、空白かアンダースコアかの違いだけなら、同じページとして扱われる。

### US-09 ページを一覧できる(P3)

読み手として、プロジェクトのページを、更新順などで一覧したい。最近の動きを把握したいからだ。

- ページがカードとして並び、タイトル・冒頭・画像が見える。
- 更新日時・作成日時・リンクされている数などで並べ替えられる。
- ページを一覧の先頭に固定できる。

### US-10 すぐ見つかる(P3)

読み手として、タイトルの一部や本文の言葉からページを探したい。どこに書いたか覚えていなくても辿り着きたいからだ。

- タイトルは、入力するたびに候補が絞り込まれる(あいまいな一致を含む)。
- 本文の全文検索ができる。日本語でも検索できる。

## 入る・招く

### US-11 Google アカウントで入れる(P4)

書き手として、新しいパスワードを作らずにログインしたい。すぐに使い始めたいからだ。

- Google アカウントでログイン・ログアウトできる。
- 表示名とアイコンを設定でき、`[名前.icon]` で自分のアイコンを本文に置ける。

### US-12 プロジェクトに招待できる(P4)

管理者として、リンクを送るだけでメンバーを招きたい。参加の手間を小さくしたいからだ。

- プロジェクトを作成でき、招待リンクを発行・無効化できる。
- プロジェクトを公開(誰でも閲覧可)か非公開(メンバーのみ)にできる。
- メンバーでない人は、非公開プロジェクトのページもAPIも見られない。

## 貼る・残す

### US-13 画像を貼れる(P5)

書き手として、画像を貼り付けやドラッグで本文に入れたい。言葉で説明しにくいものを見せたいからだ。

- 貼り付けまたはドロップした画像がアップロードされ、その位置に表示される。
- 非公開プロジェクトの画像は、メンバーでない人には見えない。

### US-14 データを持ち出せる(P5)

管理者として、プロジェクトの全ページを書き出し、読み込み直したい。バックアップと移行の手段を持ちたいからだ。

- プロジェクトの全ページを1つのファイルに書き出せる。
- 書き出したファイルを読み込むと、同じ内容のページが復元される。

## 自分好みにする

### US-15 見た目と動作を拡張できる(P6)

書き手として、自分やプロジェクト用のCSSとスクリプトを、ページに書くだけで適用したい。使い方に合わせて道具を調整したいからだ。

- 設定用のページに書いたCSSが、プロジェクトの表示に反映される。
- 自分のページに書いたスクリプトが、自分の画面で実行される。

### US-16 スマートフォンでも使える(P6)

書き手として、スマートフォンからも読み書きしたい。外出先で思いついたことを書き留めたいからだ。

- 画面幅に応じて表示が調整される。
- ホーム画面に追加して、アプリのように起動できる。
